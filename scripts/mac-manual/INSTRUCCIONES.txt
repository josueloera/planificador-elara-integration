PLANIFICADOR PRIMARIA 1.0.15 - INSTALACION MANUAL PARA MAC

1. Abre el DMG.
2. Abre Terminal (Aplicaciones > Utilidades).
3. Escribe bash seguido de un espacio, arrastra Instalar Planificador.command desde el DMG a Terminal y pulsa Enter.

El asistente comprueba la firma local, instala en tu carpeta de usuario Applications y abre el Planificador. Quita la cuarentena solo de la copia instalada; no desactiva Gatekeeper. Si existe una version en esa carpeta, la conserva como respaldo. No modifica bases de datos ni licencia.

La firma es local (ad hoc), no una certificacion de Apple. Este paquete es para instalacion manual; la actualizacion automatica de las versiones sin Developer ID tiene un fallo conocido y no debe considerarse validada.
